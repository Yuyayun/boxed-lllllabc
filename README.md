# 箱装辣白菜

SillyTavern 聊天保存状态与备份扩展，帮助你查看备份、找回丢失或误改的聊天内容。

**当前版本：1.0.1。** 本分支已整理为正式版本号，尚未合并 main 或发布 Release。使用与本分支配套的服务器插件；[main 分支](https://github.com/Yuyayun/boxed-lllllabc/tree/main)目前仍为已发布的 1.0.0。

只安装前端就能使用浏览器本地备份（IndexedDB）。[服务器插件](https://github.com/Yuyayun/boxed-lllllabc-server)是可选组件；安装后仍由你决定是否切换位置，不会自动迁移，也不会同步两个位置的数据。

## 安装与更新

参与本次开发版验收，可以使用配套测试包，或下载当前分支的 ZIP。解压后，将前端目录命名为 `boxed-lllllabc`，放到酒馆的：

```text
public/scripts/extensions/third-party/boxed-lllllabc
```

也可以在酒馆根目录使用 Git 安装当前测试分支：

```sh
git clone --branch gpt/1.0.1-migration https://github.com/Yuyayun/boxed-lllllabc.git public/scripts/extensions/third-party/boxed-lllllabc
```

刷新页面后，在扩展设置中展开“箱装辣白菜”。前端没有额外的 npm 安装步骤，也不要求安装服务器插件。

Git 安装的扩展可在其目录执行 `git pull --ff-only` 更新当前分支。使用 ZIP 更新时，先把旧代码目录移到扩展目录以外留存，再放入新目录，避免同时加载两份扩展。更新前结束生成和正在进行的存储操作，保留浏览器站点数据。

使用服务器存储时，前后端都应使用本测试分支的配套版本。普通扩展安装入口输入仓库地址时获得的是 main 上的正式版，不包含本开发分支尚未发布的改进。

## 开始使用

1. 打开角色聊天或群聊，确认“启用备份”已开启。
2. 从最新楼层的状态提示、聊天区顶部提示或扩展设置进入“当前聊天备份”。
3. 需要手动留存一份完整内容时，使用“创建聊天快照”。
4. 找回内容前，先打开对应聊天，再预览备份并确认恢复范围。

“检查保存状态”读取酒馆聊天文件，确认当前内容是否已保存；“请求酒馆保存”会请求酒馆保存并继续核对。箱装备份是另外保留的副本，聊天文件保存成功不等于完成了设备外部备份。

## 四类普通备份

| 类型 | 默认状态 | 用途 |
|---|---|---|
| 最近楼层备份 | 开启，最近 20 层 | 保留最近一段聊天及候选回复，方便补回缺失的尾部内容；可调整为 1–200 层。 |
| 未保存变更 | 随普通备份记录 | 保护尚未确认保存到酒馆聊天文件中的消息、编辑、候选切换和聊天结构改动。 |
| 完整聊天备份 | 关闭 | 开启后，为打开过的聊天维护从第 0 层开始的完整副本。 |
| 历史楼层改动备份 | 开启 | 保留最近备份范围以外的楼层改动及其候选回复。 |

关闭最近楼层备份后，未保存变更仍可受到保护；关闭备份总开关则停止普通备份与保存状态核对。手动快照仍可使用。

如果聊天突然少了很多楼层，完整备份会先暂停更新并保留原副本。请检查聊天和预览内容，确认无误后再处理，普通清理不会直接删除这份受保护的备份。

聊天改名后会尽量接续原有备份。原生分支聊天（Branch）和检查点（Checkpoint）各自保留备份，不与父聊天混用；无法确认对应关系时先保留数据。

## 聊天快照

“创建聊天快照”手动保存当前完整聊天、全部候选回复、选中的候选以及聊天附带信息。快照独立保留，不随日常备份更新或普通清理而改变。

在“管理聊天快照”中可以预览、重命名、单独删除和恢复。即使关闭普通备份，也可以手动创建快照。没有创建完成的快照不能恢复。

恢复前需要打开快照所属的聊天。预览并确认后，当前聊天会被快照内容覆盖，源快照仍然保留。

## 恢复与保存检查

在“恢复备份”中选择需要的类型和范围，先预览，再确认替换、补回或完整恢复。恢复会使用酒馆正常的显示和保存流程。

界面已经显示内容，不代表酒馆聊天文件一定保存成功。保存还在等待确认时，可以稍后再检查，不必反复恢复。

“请求酒馆保存”不会立即删除未保存变更；确认相应内容已经保存后，才移除对应的待保存记录。

## 备份存放位置

| 位置 | 使用条件 | 需要了解的事情 |
|---|---|---|
| 浏览器本地存储（IndexedDB） | 默认，无需后端 | 属于当前浏览器和酒馆站点。清理站点数据、更换浏览器或访问地址，可能让原备份不可见。 |
| 服务器存储（SQLite） | 自愿安装配套服务器插件 | 备份保存在酒馆服务器的独立目录中；插件只负责箱装备份，不代替酒馆保存聊天文件。 |

当前浏览器只读写一个位置。两处不会自动同步，安装插件或检查连接也不会改变当前选择。

### 切换位置

停止生成并关闭其他酒馆页签，在设置中点击“切换备份位置”。**新位置已有的箱装备份会被覆盖，不会合并**，请先确认范围。

切换会分批清点、搬运并核对内容，全部检查完成后才启用新位置。进度中的已核验数量，表示已经从新位置读回确认的记录。设备较慢时会显示当前阶段和等待情况。

成功后，原位置的备份仍保留，但后续只更新当前选中的位置。若需要清空旧副本，再单独确认“清空原位置的备份”；它不会清理当前位置或酒馆聊天文件。

### 暂停、中断和恢复

可以请求暂停，扩展会在当前步骤结束后停下。刷新或重启后，需要明确选择继续核对，或放弃尚未完成的任务；备份操作在此期间保持暂停。

如果最初清点尚未完成，或来源内容已经变化，任务可能安全撤销，保留两端原数据后重新开始。已经启用新位置的任务只继续收尾，不会误回到旧位置。连接失败时保留任务，不自动换用另一端。

### 查看运行日志

连接配套后端后，存储状态附近会出现默认折叠的“查看运行日志”。可以筛选异常、搬家、清理旧位置、日常或全部，翻看更早记录并复制当前页。

从未连接过后端时隐藏入口；曾连接、目前断线时保留入口和无法读取提示。清理已结束日志需要确认，未结束任务的记录及备份数据会保留。日志不包含聊天正文或密钥。

运行日志暂时写不了时会单独提示，备份操作仍按自身结果显示。普通进度会合并记录，暂停、异常和完成等重要结果及时保留；日志不代替恢复任务所需的正式记录。

## 查看与清理

“查看全部聊天备份”可以按角色或群聊查找、搜索及预览。普通批量清理会先展示范围和预计结果，再由你确认；未保存变更、暂停更新或等待确认的完整备份、聊天快照会保留。

如果预览后数据发生变化，需要重新预览。遇到断线或结果尚未确认时，先重新核对，不要直接重试旧清理计划。

## 兼容性与测试状态

本机已检查 SillyTavern 1.15.0、1.19.0，完成约 479 MB 级、超过 1 GiB 数据的往返、重启与旧版数据升级检查。手机 Termux、真实软键盘及 Safari 的结果不能由桌面测试代替。

使用当前分支时，前后端需配套更新；浏览器旧备份升级后仍留在浏览器，不自动迁往服务器。更详细的结果见[本机验收记录](docs/acceptance/1.0.1-desktop-acceptance.md)，手机步骤见[Termux 验收清单](docs/acceptance/1.0.1-termux-checklist.md)。
