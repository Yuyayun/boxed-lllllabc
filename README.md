# 箱装辣白菜

**当前版本：1.0.0。** SillyTavern 聊天保存状态与独立备份扩展。

箱装辣白菜帮助你确认当前聊天是否已保存到**酒馆聊天文件**，并保留可预览、可恢复的**备份**。备份不会写入聊天正文或模型提示词。

**只安装本扩展即可使用浏览器本地存储（IndexedDB）。** [服务器存储插件](https://github.com/Yuyayun/boxed-lllllabc-server)是可选组件；安装、启用或检查插件不会自动切换备份位置，也不会自动迁移、同步或双写。

## 安装与更新

在 SillyTavern 的扩展管理中选择“安装扩展”，输入：

```text
https://github.com/Yuyayun/boxed-lllllabc
```

也可以在酒馆根目录手动安装：

```sh
git clone --branch main https://github.com/Yuyayun/boxed-lllllabc.git public/scripts/extensions/third-party/boxed-lllllabc
```

安装后刷新页面，在扩展设置中展开“箱装辣白菜”。不需要安装服务器插件或额外的前端 npm 依赖。

更新前先结束生成和正在进行的备份操作。可使用酒馆扩展管理或扩展信息中的更新入口，由用户确认更新；手动安装可在扩展目录执行 `git pull --ff-only`。使用 SQLite 时请同时核对配套服务器插件版本。

## 开始使用

1. 确认“启用备份”已开启；最近楼层默认备份 20 层，可调整为 1–200 层。
2. 打开角色聊天或群聊，通过最新楼层状态灯、聊天区顶部状态条或扩展设置进入“当前聊天备份”。
3. “检查保存状态”只读取酒馆聊天文件，不发起保存；“请求酒馆保存”请求酒馆保存当前聊天并检查结果。
4. 手动存档使用“创建聊天快照”；恢复前先打开对应聊天，再进入“恢复备份”或快照预览。

“酒馆聊天已保存”说明当前聊天与读到的酒馆聊天文件一致，不代表完成了设备外部备份。等待确认或读取失败时，已有备份和未保存变更会保留。

## 四类普通备份

| 类型 | 默认状态 | 用途 |
|---|---|---|
| 最近楼层 | 开启，最近 20 层 | 保存最近 N 层及全部候选回复，用于补回缺失的尾部内容。 |
| 未保存变更 | 随普通备份记录 | 保存已被备份记录、但尚未确认保存到酒馆聊天文件中的消息、编辑、候选切换或结构改动。 |
| 完整聊天 | 默认关闭 | 开启后，为打开过的聊天维护从第 0 层开始的完整副本。 |
| 历史楼层改动 | 默认开启 | 保留最近 N 层范围以外的楼层改动及其候选回复。 |

完整备份遇到疑似异常缩短时会暂停更新并保留原副本。请先检查聊天和备份预览，再使用对应确认处理入口；普通清理不能绕过这项保护。

聊天改名会在证据充分时接续原有备份。原生 Branch / Checkpoint 属于新的逻辑聊天，即使旧酒馆沿用同一 UUID，也不会据此混用父聊天备份。有歧义时保留数据，不猜测合并。

## 聊天快照

“创建聊天快照”手动保存当前完整聊天、消息字段、所有候选回复及选中状态、聊天元数据。快照独立保留，不随日常聊天、普通备份更新或普通清理改变，也不会新建酒馆聊天文件。

在“管理聊天快照”中可以预览、重命名、单独删除和恢复。快照没有启用开关，即使普通备份总开关关闭仍可手动操作。创建未完成的存档不能恢复，可经确认后单独删除。

恢复快照前须打开它所属的聊天；预览并再次确认后，会覆盖当前聊天的完整内容和可恢复元数据。源快照保留，目标酒馆聊天身份不变。

## 恢复与保存检查

“恢复备份”展示四类备份、当前可恢复范围及冲突。请先预览，再确认替换、补回或完整恢复的影响范围。恢复复用酒馆显示和保存流程；界面变化、保存请求返回或等待超时，都不等于酒馆聊天文件已保存成功。

“请求酒馆保存”不会恢复、覆盖或删除备份，也不会立即清除未保存变更。确认酒馆聊天文件已保存相应内容后，才会核销对应记录。保存待确认时可稍后重新检查，不必反复恢复。

## 备份存放位置

| 位置 | 使用条件 | 数据与空间统计 |
|---|---|---|
| 浏览器本地存储（IndexedDB） | 默认，无需服务器插件 | 备份属于当前浏览器和酒馆站点；浏览器占用与可用空间是整个站点的估算，不是扩展独占配额。 |
| 服务器存储（SQLite） | 自愿安装并启用独立服务器插件 | 备份位于酒馆服务器的专用数据库；分别展示备份占用、数据库及日志占用、服务器磁盘可用空间。 |

当前浏览器只使用其中一个位置。没有自动同步、双写或跨设备同步；服务器存储也不代表多个浏览器会自动协调。清理站点数据、切换浏览器、设备或酒馆地址可能使原浏览器备份不可见或被删除。

### 切换备份位置

1. 停止生成、关闭其他酒馆页签，确保两个位置可用并留有复制及回滚空间。
2. 在设置中点击“切换备份位置”并明确确认：**新位置已有的箱装备份会被完整覆盖，不会合并。**
3. 扩展复制并校验全部备份及快照，完成后才切换当前使用位置；成功后原位置的备份仍保留。

刷新或重启后会恢复未完成操作。恢复时服务器不可用会保留记录并暂停，不会擅自写到另一个位置；请恢复连接后重试，不要手动删除数据库、控制记录或任务锁。

成功切换后，“清空原位置的备份”才会开放。此操作会删除原位置中的普通备份、未保存变更和快照；当前使用位置、备份设置和酒馆聊天文件不受影响，需要单独确认。

## 查看与清理备份

“查看全部聊天备份”支持汇总、搜索、角色/群聊分组、每聊天四类概况及单聊天管理。设置和弹窗继承酒馆主题，适配窄栏、桌面和手机视口。

批量清理支持全部聊天、单角色/群聊全部、单角色内多选和跨角色多选。只清理当前备份位置中的最近、完整和历史普通备份；**未保存变更、已暂停更新或等待酒馆确认的完整备份不会删除，聊天快照保留。** 目录搜索不会缩小“全部”范围，以预览为准。

范围或数据在预览后变化会拒绝旧计划。显示“结果未确认”时，请先刷新核对实际数据，再重新预览，不要直接重试旧计划。清理不会关闭备份开关，后续聊天仍可能重新产生备份。

## 兼容性与常见问题

- 已验证 SillyTavern **1.15.0、1.19.0**；建议使用支持 IndexedDB 的现代浏览器。快照校验与存储切换需要相应 Web Crypto / Web Locks 能力，推荐通过 `localhost` 或 HTTPS 使用。
- 前端 **1.0.0** 与服务器插件 **1.0.0** 配套使用协议 **5**；IndexedDB schema **7**，SQLite schema **3**。旧浏览器备份升级后默认仍留在 IndexedDB，不自动迁入服务器。
- SQLite 插件仅支持默认用户或可信的唯一启用账户，不支持多个启用账户。插件缺失不影响单独使用 IndexedDB；已选择 SQLite 时遇到断线或协议不兼容，不会自动回退。
- 空间不足、只读或校验失败会明确提示，不会自动删除已有备份。超大记录或单聊天仍可能触发读取/请求上限，详见[服务器插件说明](https://github.com/Yuyayun/boxed-lllllabc-server)。
- 两个酒馆版本的软件、数据库和指定规模验收已有记录；真实手机软键盘、Safari、任意第三方主题及外部模型生成尚未全面验收，不将桌面视口模拟等同真机验证。
