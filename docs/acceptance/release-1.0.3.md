# 1.0.3 正式发布核对

日期：2026-11-20。前后端从 `codex/1.0.3-backup-race` 快进合并至各自 `main`，配套发布附注 Tag `v1.0.3` 和正式 GitHub Release。

## 发布范围

- 前端运行代码基线为 `b68c38a`，后端为 `3f7e6b9`。本次发布整理更新正式 README、验收索引与记录，未增加运行逻辑。
- 修复旧楼层修改备份中断后的漏补和恢复旧正文；保护记录在对应备份得到核对前保留，刷新或重启后接续。
- 备份正文按类型区分版本，避免保存核对状态或保护记录写入干扰分页；读取有界重试，预览失败不再改变聊天保存状态。
- 修复手机顶部“当前聊天操作”的异常空白；明确连接、分批读写、快照、清理与存储切换日志的对象、阶段及错误指引。
- 前端 manifest/package/设置显示/内置公告及后端 package/status 均为 1.0.3。IndexedDB schema 8、SQLite schema 4、协议 6 不变，无需清库或重新迁移。
- 使用服务器存储时，两端需一并更新。旧接口保留；旧后端缺少核销证明能力时保留保护记录并提示更新，不将结果未知当作成功。
- 30 个共享模块逐字节一致；服务器明确选择 UTC 控制台显示，浏览器使用设备本地时间，底层 UTC 时间戳不变。
- 1.0.3 使用 CC BY-NC-SA 4.0；此前版本仍适用各自发布时附带的许可证。

## 边界

全部自动化使用独立临时数据。手机视口和触摸由桌面 Edge 模拟，不代替 Android/Termux、iOS/Safari、真实软键盘及实际网络验收。用户反馈本轮测试可用，未据此扩大为所有设备均已验证。

发布不访问或修改真实聊天、备份库，不自动切换存储或迁移数据；此前已经丢失且任何副本均未保留的正文不能凭空重建。启动检查取消的日志已明确对象与提示，未将它描述成已证明修复所有现场断连原因。
