# 箱装辣白菜 1.0.0 发布检查

日期：2026-10-27。本轮按用户明确授权整理正式版、将两个开发分支纳入各自 main，并创建 `v1.0.0` 标签及 GitHub Release。本文记录发布检查范围；实际发布位置以两个仓库的 main、标签和 Release 为准，不改写历史阶段报告。

## 版本与交付范围

- 前端：`package.json`、`manifest.json`、设置中的版本行统一为 **1.0.0**，保留仓库名、作者署名和安装/更新钩子。
- 独立服务器插件：`package.json` 与状态接口版本统一为 **1.0.0**。
- 两端协议仍为 **5**，IndexedDB schema **7**、SQLite schema **3**；本轮没有数据库结构或业务算法变更。
- 将此前未提交的设置模板及 4 个 CSS 文件纳入正式版，包括窄设置栏中当前聊天操作的容器自适应布局。
- 重写两仓库 README：前端面向使用者，后端面向服务器安装/配置；CHANGELOG 整理为正式 1.0.0 功能。原有 P1–P7 及后续修复记录保留，不将历史记录中的旧版本号改写为当前版本。
- 需求原文、旧未跟踪文档、真实或虚构聊天、数据库、日志、浏览器资料与截图不参与提交。
