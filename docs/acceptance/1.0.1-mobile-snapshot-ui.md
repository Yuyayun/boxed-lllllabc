# 1.0.1 手机弹窗与快照交互收尾

日期：2026-10-29。范围仅限前端两处交互问题。

## 修复

- 「当前聊天备份」正文的 Grid 按内容排布并顶部对齐，保留原有正文滚动容器。
- 窄屏标题纵向排列时，移除说明文字沿用的 `15em` 伸缩基准。隔离宿主修复前测得说明文字高度为 175.5px，修复后按文本自然高度排列。
- 四种快照操作通过同一个 `perform` 成功收尾入口关闭弹窗；先恢复关闭能力，再执行关闭，不增加成功确认页面。
- 创建采用控制器完成校验后的成功结果；恢复要求 `ok` 与 `confirmed` 同时成立；删除要求 `deleted`；重命名要求返回对应快照及已保存名称。异常及未确认结果保留原因和可操作控件。

## 验证

- 前端现有自动化测试：313/313 通过。
- 新增浏览器契约 `tests/browser/snapshot-ui-contract.js`：创建、恢复、重命名、删除分别覆盖成功、未确认、异常，共 12 项通过。
- 上述浏览器契约使用延迟控制器结果，验证操作未完成时禁用按钮并拦截关闭，完成后再依据返回结果收尾；未确认酒馆保存的恢复不能自动关闭。此契约不替代真实数据控制器测试。
- 隔离 SillyTavern 1.15.0 加载完整宿主样式及当前扩展，使用虚构展示数据检查 390×760、360×640、390×420 和 1200×900 布局。标题及按钮紧凑、四个入口保留、无横向溢出、长正文可滚动至底部，页面错误为零。
- 手机触屏模拟复验：上述三种窄屏分别发送实际触摸开始、连续移动、结束事件，正文均产生滚动；四种快照操作的 12 项交互检查再次通过。此项为浏览器设备模拟，不是手机实机验收。
- CSS 结构检查无错误；布局检查无新增发现。已有宿主和运行时提供的 CSS 变量不作本轮修改。

## 边界

只修改 `style.css` 中当前聊天弹窗的局部规则及 `src/ui/snapshots.js` 的交互收尾；按钮回调、快照控制器、数据处理、校验、保存与恢复机制均未修改。后端无改动。本轮未操作 main、Tag 或 Release。
