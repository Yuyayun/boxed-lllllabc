# 1.0.5-fix.2 后端插件版本展示

日期：2026-11-26。基准为前端修复分支的 `12b254e`，版本仍为 1.0.5-fix.2。仅修改前端，后端、数据库版本、协议与备份策略不变。

“备份存放位置”原连接提示现在追加后端状态接口实际返回的 `pluginVersion`，例如“服务器备份插件已连接 · 后端版本 1.0.5-fix.1”。不根据前端版本推断后端，也不因版本号不同而改变迁移能力判定。

- 未提供版本字段、字段不是字符串、包含内嵌控制字符或超过 80 字符时显示“后端版本未知”。正常字符串修剪首尾空白，按纯文本显示。
- 后端只读时保留原只读提示并显示版本；连接检查失败时显示未连接，清除之前显示的版本。
- 手动检查和原有 SQLite 状态回调都会更新此提示；没有新增轮询、接口或存储写入。相同文本不重复修改状态节点。
- 当前仍使用 IndexedDB 时也可看到已安装后端的版本，显示版本不会切换或迁移备份。界面样式及窄屏换行沿用原连接提示。

本地后端现有状态接口已经返回该字段，因此不要求升级后端。数据库故障或协议不兼容导致状态接口失败时，本次不额外查询独立版本接口；不把上次成功的版本冒充当前状态。
